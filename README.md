<h4 align="center">Parallel Computing & Distributed Systems Course Project</h4>


__SmartCity-IoT-Sim__ is a software-based hardware-less simulation framework designed to mimic data ingestion from heterogeneous IoT nodes in a smart city infrastructure. It aims to demonstrate thread-based parallelism, concurrent resource synchronization, and real-time streaming telemetry aggregation.
